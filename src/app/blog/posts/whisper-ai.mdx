## Introduction

OpenAI Whisper is a state-of-the-art automatic speech recognition (ASR) system that has revolutionized how we approach voice transcription. Released in September 2022, Whisper achieves human-level accuracy across multiple languages and accents, making professional-grade speech recognition accessible to everyone.

This comprehensive guide will help you understand, implement, and optimize Whisper for your applications.

## What is Whisper?

Whisper is a multi-purpose speech recognition model trained on 680,000 hours of multilingual and multitask supervised data. Unlike traditional ASR systems, Whisper can:

- Transcribe speech in 99+ languages
- Translate speech to English
- Detect language automatically
- Handle diverse audio conditions (background noise, accents, music)
- Provide timestamps for individual words
- Distinguish between speakers in some cases

### Key Features

- **Multilingual**: Supports nearly 100 languages
- **Robust**: Works with noisy, real-world audio
- **Versatile**: Transcription, translation, and language identification
- **Open Source**: Free to use and modify
- **Multiple Sizes**: From tiny (39M params) to large (1550M params)

## Model Variants

Whisper comes in five sizes, each with different trade-offs:

| Model  | Parameters | English-only | Multilingual | Speed | Accuracy  |
| ------ | ---------- | ------------ | ------------ | ----- | --------- |
| tiny   | 39M        | ✓            | ✓            | ~32x  | Good      |
| base   | 74M        | ✓            | ✓            | ~16x  | Better    |
| small  | 244M       | ✓            | ✓            | ~6x   | Great     |
| medium | 769M       | ✓            | ✓            | ~2x   | Excellent |
| large  | 1550M      | ✗            | ✓            | 1x    | Best      |

**Choosing a Model:**

- **tiny/base**: Real-time applications, resource-constrained environments
- **small**: Good balance for most applications
- **medium/large**: Maximum accuracy, offline batch processing

## Basic Usage

### Python - Local Model

```python
import whisper

# Load model (downloads on first run)
model = whisper.load_model("base")

# Transcribe audio file
result = model.transcribe("audio.mp3")

print(result["text"])
# Output: "Hello, this is a test transcription."

# Access detailed information
print(result["language"])  # Detected language
print(result["segments"])  # Timestamped segments

# Example with options
result = model.transcribe(
    "audio.mp3",
    language="en",          # Force language (skip detection)
    task="translate",       # Translate to English
    verbose=True,           # Show progress
    temperature=0.0,        # Deterministic output
    word_timestamps=True   # Get word-level timestamps
)

# Print segments with timestamps
for segment in result["segments"]:
    print(f"[{segment['start']:.2f}s -> {segment['end']:.2f}s] {segment['text']}")
```

### Python - OpenAI API

```python

client = OpenAI(api_key="your-api-key")

# Transcribe audio

    transcript = client.audio.transcriptions.create(

        file=audio_file,
        response_format="text"

print(transcript)

# With detailed response
with open("audio.mp3", "rb") as audio_file:
    transcript = client.audio.transcriptions.create(
        model="whisper-1",
        file=audio_file,
        response_format="verbose_json",
        timestamp_granularities=["word", "segment"]
    )

# Access word-level timestamps
for word in transcript.words:
    print(f"{word['word']}: {word['start']}s - {word['end']}s")

# Translate to English
with open("audio.mp3", "rb") as audio_file:
    translation = client.audio.translations.create(
        model="whisper-1",
        file=audio_file
    )

print(translation.text)
```

### Node.js - OpenAI API

```javascript
import OpenAI from "openai";
import fs from "fs";

const client = new OpenAI({
  apiKey: process.env.OPENAI_API_KEY,
});

// Transcribe audio file
async function transcribeAudio(filePath) {
  const transcript = await client.audio.transcriptions.create({
    file: fs.createReadStream(filePath),
    model: "whisper-1",
    response_format: "verbose_json",
    timestamp_granularities: ["word", "segment"],
  });

  console.log("Full text:", transcript.text);

  // Word-level timestamps
  transcript.words.forEach((word) => {
    console.log(`${word.word}: ${word.start}s - ${word.end}s`);
  });

  return transcript;
}

// Translate to English
async function translateAudio(filePath) {
  const translation = await client.audio.translations.create({
    file: fs.createReadStream(filePath),
    model: "whisper-1",
  });

  return translation.text;
}

// Usage
async function main() {
  try {
    const result = await transcribeAudio("audio.mp3");
    console.log("Transcription:", result.text);

    const translation = await translateAudio("spanish.mp3");
    console.log("Translation:", translation);
  } catch (error) {
    console.error("Error:", error);
  }
}

main();
```

## Real-World Use Cases

### 1. Meeting Transcription

```python
import whisper
import os
from datetime import datetime

class MeetingTranscriber:
    def __init__(self, model_size="small"):
        self.model = whisper.load_model(model_size)

    def transcribe_meeting(self, audio_file):
        # Transcribe with timestamps
        result = self.model.transcribe(
            audio_file,
            word_timestamps=True,
            task="transcribe"
        )

        # Generate formatted transcript
        transcript = self.format_transcript(result)

        # Save to file
        timestamp = datetime.now().strftime("%Y%m%d_%H%M%S")
        filename = f"meeting_transcript_{timestamp}.txt"

        with open(filename, 'w', encoding='utf-8') as f:
            f.write(transcript)

        return filename

    def format_transcript(self, result):
        lines = []
        lines.append(f"Meeting Transcript")
        lines.append(f"Generated: {datetime.now().strftime('%Y-%m-%d %H:%M:%S')}")
        lines.append(f"Language: {result['language']}")
        lines.append("=" * 80)
        lines.append("")

        for segment in result["segments"]:
            timestamp = f"[{self.format_time(segment['start'])}]"
            lines.append(f"{timestamp} {segment['text'].strip()}")

        return "\\n".join(lines)

    def format_time(self, seconds):
        minutes = int(seconds // 60)
        secs = int(seconds % 60)
        return f"{minutes:02d}:{secs:02d}"

# Usage
transcriber = MeetingTranscriber()
output_file = transcriber.transcribe_meeting("meeting.mp3")
print(f"Transcript saved to: {output_file}")
```

### 2. Video Content Analysis

```python
import whisper
import subprocess
import json

class VideoAnalyzer:
    def __init__(self):
        self.model = whisper.load_model("base")

    def extract_audio(self, video_file):
        """Extract audio from video using FFmpeg"""
        audio_file = "temp_audio.mp3"
        subprocess.run([
            'ffmpeg', '-i', video_file,
            '-vn', '-acodec', 'mp3',
            '-y', audio_file
        ], capture_output=True)
        return audio_file

    def analyze_video(self, video_file):
        # Extract audio
        audio_file = self.extract_audio(video_file)

        # Transcribe
        result = self.model.transcribe(audio_file)

        # Analyze content
        analysis = {
            'duration': max(seg['end'] for seg in result['segments']),
            'language': result['language'],
            'word_count': len(result['text'].split()),
            'transcript': result['text'],
            'segments': len(result['segments'])
        }

        return analysis

# Usage
analyzer = VideoAnalyzer()
analysis = analyzer.analyze_video("presentation.mp4")
print(json.dumps(analysis, indent=2))
```

## Performance Optimization

### 1. Choose the Right Model

- **Real-time**: Use `tiny` or `base`
- **Accuracy-critical**: Use `medium` or `large`
- **Batch processing**: Use `large` with GPU

### 2. GPU Acceleration

```python
import whisper
import torch

# Check GPU availability
device = "cuda" if torch.cuda.is_available() else "cpu"
print(f"Using device: {device}")

# Load model on GPU
model = whisper.load_model("base", device=device)

# Transcribe with GPU
result = model.transcribe("audio.mp3", fp16=True)  # Use half precision
```

### 3. Batch Processing

```python
import whisper
from concurrent.futures import ThreadPoolExecutor
import os

def transcribe_file(file_path, model):
    result = model.transcribe(file_path)
    output_path = f"{os.path.splitext(file_path)[0]}.txt"

    with open(output_path, 'w', encoding='utf-8') as f:
        f.write(result['text'])

    return output_path

def batch_transcribe(audio_files, model_size="base", max_workers=4):
    model = whisper.load_model(model_size)

    with ThreadPoolExecutor(max_workers=max_workers) as executor:
        futures = [
            executor.submit(transcribe_file, file, model)
            for file in audio_files
        ]

        results = [future.result() for future in futures]

    return results

# Process multiple files
files = ['audio1.mp3', 'audio2.mp3', 'audio3.mp3']
outputs = batch_transcribe(files)
print(f"Transcribed {len(outputs)} files")
```

## Best Practices

1. **Pre-process audio**: Convert to 16kHz mono for best results
2. **Handle errors gracefully**: Audio quality affects accuracy
3. **Use appropriate model size**: Balance speed and accuracy
4. **Cache models**: Load once, reuse for multiple files
5. **Monitor resource usage**: Large models need significant RAM/VRAM
6. **Set language when known**: Skips detection step
7. **Use timestamps**: Helpful for video editing and navigation
