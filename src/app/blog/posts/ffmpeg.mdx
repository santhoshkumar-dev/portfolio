## Introduction

FFmpeg is the Swiss Army knife of multimedia processing. Whether you're converting video formats, extracting audio, creating thumbnails, streaming content, or building a video platform, FFmpeg is the industry-standard tool that powers everything from YouTube to Netflix.

This comprehensive guide will take you from FFmpeg basics to advanced techniques, enabling you to harness its full potential for your projects.

## What is FFmpeg?

FFmpeg is a complete, cross-platform solution for recording, converting, and streaming audio and video. It's a command-line tool and a collection of libraries that can:

- Convert between virtually any media format
- Encode and decode audio/video streams
- Apply filters and effects
- Stream media over networks
- Extract metadata and generate thumbnails
- Concatenate, split, and manipulate media files

### Core Components

- **ffmpeg**: Command-line tool for converting and processing media
- **ffprobe**: Analyze media files and extract metadata
- **ffplay**: Simple media player for testing
- **libavcodec**: Codec library supporting hundreds of formats
- **libavformat**: Muxer/demuxer library for container formats
- **libavfilter**: Filter library for audio/video processing

## Basic Concepts

### Understanding Media Files

Media files have three main components:

1. **Container** (e.g., MP4, MKV, AVI): Wraps streams and metadata
2. **Video Codec** (e.g., H.264, VP9, AV1): Compresses video data
3. **Audio Codec** (e.g., AAC, MP3, Opus): Compresses audio data

### FFmpeg Command Structure

```bash
ffmpeg [global options] [input options] -i input.mp4 [output options] output.mp4

# Example
ffmpeg -i input.mp4 -c:v libx264 -c:a aac output.mp4
```

## Common Operations

### 1. Format Conversion

Convert between different container formats:

```bash
# MP4 to WebM
ffmpeg -i input.mp4 -c:v libvpx-vp9 -c:a libopus output.webm

# AVI to MP4
ffmpeg -i input.avi -c:v libx264 -c:a aac output.mp4

# MOV to MKV
ffmpeg -i input.mov -c copy output.mkv  # Just repackage without re-encoding
```

### 2. Video Compression

Reduce file size while maintaining quality:

```bash
# High quality (CRF 18-23)
ffmpeg -i input.mp4 -c:v libx264 -crf 23 -preset slow -c:a aac -b:a 128k output.mp4

# Medium quality (CRF 24-28)
ffmpeg -i input.mp4 -c:v libx264 -crf 26 -preset medium output.mp4

# Web optimized
ffmpeg -i input.mp4 -c:v libx264 -crf 28 -preset fast -movflags +faststart output.mp4

# CRF scale: 0 (lossless) to 51 (worst quality)
# Lower CRF = better quality, larger file
```

### 3. Resolution and Scaling

Resize videos to different resolutions:

```bash
# Scale to specific resolution
ffmpeg -i input.mp4 -vf scale=1280:720 output.mp4

# Scale to 720p maintaining aspect ratio
ffmpeg -i input.mp4 -vf scale=-2:720 output.mp4

# Scale to 50% of original size
ffmpeg -i input.mp4 -vf scale=iw/2:ih/2 output.mp4

# 4K to 1080p
ffmpeg -i input_4k.mp4 -vf scale=1920:1080 output_1080p.mp4
```

### 4. Trim and Cut Videos

Extract specific portions:

```bash
# Extract from 00:30 to 01:30 (1 minute)
ffmpeg -i input.mp4 -ss 00:00:30 -to 00:01:30 -c copy output.mp4

# Extract 10 seconds starting at 00:05:00
ffmpeg -i input.mp4 -ss 00:05:00 -t 10 -c copy output.mp4

# Fast seeking (less accurate but faster)
ffmpeg -ss 00:05:00 -i input.mp4 -t 10 -c copy output.mp4
```

### 5. Extract Audio

Get audio from video files:

```bash
# Extract audio as MP3
ffmpeg -i input.mp4 -vn -c:a libmp3lame -b:a 192k output.mp3

# Extract audio as AAC
ffmpeg -i input.mp4 -vn -c:a aac -b:a 128k output.aac

# Extract without re-encoding
ffmpeg -i input.mp4 -vn -c:a copy output.aac
```

### 6. Generate Thumbnails

Create image previews:

```bash
# Single thumbnail at 5 seconds
ffmpeg -i input.mp4 -ss 00:00:05 -vframes 1 thumbnail.jpg

# Multiple thumbnails (1 per second)
ffmpeg -i input.mp4 -vf fps=1 thumbnail_%03d.jpg

# Thumbnail at specific size
ffmpeg -i input.mp4 -ss 00:00:05 -vf scale=320:180 -vframes 1 thumb.jpg
```

## Working with Codecs

### Video Codecs

#### H.264 (AVC) - Most Compatible

```bash
# Standard H.264 encoding
ffmpeg -i input.mp4 -c:v libx264 -preset medium -crf 23 output.mp4

# Presets: ultrafast, superfast, veryfast, faster, fast, medium, slow, slower, veryslow
# Slower preset = better compression, longer encoding time

# Profile and level (for compatibility)
ffmpeg -i input.mp4 -c:v libx264 -profile:v high -level 4.0 output.mp4
```

#### H.265 (HEVC) - Better Compression

```bash
# H.265 encoding (50% smaller than H.264 at same quality)
ffmpeg -i input.mp4 -c:v libx265 -crf 28 -preset medium output.mp4

# Hardware-accelerated (NVIDIA)
ffmpeg -i input.mp4 -c:v hevc_nvenc -preset slow -crf 28 output.mp4
```

#### VP9 - Open Source, Web-Friendly

```bash
# VP9 for WebM
ffmpeg -i input.mp4 -c:v libvpx-vp9 -crf 30 -b:v 0 -c:a libopus output.webm

# Two-pass encoding (better quality)
ffmpeg -i input.mp4 -c:v libvpx-vp9 -b:v 1M -pass 1 -f null /dev/null
ffmpeg -i input.mp4 -c:v libvpx-vp9 -b:v 1M -pass 2 output.webm
```

### Audio Codecs

```bash
# AAC (most compatible)
ffmpeg -i input.mp4 -c:a aac -b:a 128k output.mp4

# MP3
ffmpeg -i input.mp4 -c:a libmp3lame -b:a 192k output.mp3

# Opus (best quality at low bitrates)
ffmpeg -i input.mp4 -c:a libopus -b:a 96k output.webm

# FLAC (lossless)
ffmpeg -i input.wav -c:a flac output.flac
```

## Advanced Filtering

FFmpeg's filter system enables powerful transformations:

### Video Filters

```bash
# Add watermark
ffmpeg -i input.mp4 -i watermark.png -filter_complex \
  "overlay=W-w-10:H-h-10" output.mp4

# Blur video
ffmpeg -i input.mp4 -vf "boxblur=5:1" output.mp4

# Rotate video
ffmpeg -i input.mp4 -vf "rotate=PI/4" output.mp4

# Speed up 2x
ffmpeg -i input.mp4 -vf "setpts=0.5*PTS" -af "atempo=2.0" output.mp4

# Slow down to 0.5x
ffmpeg -i input.mp4 -vf "setpts=2.0*PTS" -af "atempo=0.5" output.mp4

# Crop video (width:height:x:y)
ffmpeg -i input.mp4 -vf "crop=1280:720:0:0" output.mp4

# Add black bars for specific aspect ratio
ffmpeg -i input.mp4 -vf "pad=1920:1080:(ow-iw)/2:(oh-ih)/2" output.mp4
```

### Audio Filters

```bash
# Normalize audio volume
ffmpeg -i input.mp4 -af "loudnorm" output.mp4

# Fade in/out
ffmpeg -i input.mp4 -af "afade=t=in:st=0:d=3,afade=t=out:st=27:d=3" output.mp4

# Remove background noise
ffmpeg -i input.mp4 -af "highpass=f=200,lowpass=f=3000" output.mp4

# Change audio tempo without pitch shift
ffmpeg -i input.mp3 -af "atempo=1.5" output.mp3
```

## Integration with Node.js

### Using fluent-ffmpeg

```javascript
const ffmpeg = require("fluent-ffmpeg");

// Convert video
function convertVideo(inputPath, outputPath) {
  return new Promise((resolve, reject) => {
    ffmpeg(inputPath)
      .output(outputPath)
      .videoCodec("libx264")
      .audioCodec("aac")
      .on("end", () => resolve())
      .on("error", (err) => reject(err))
      .on("progress", (progress) => {
        console.log(`Processing: ${progress.percent}% done`);
      })
      .run();
  });
}

// Generate thumbnail
function generateThumbnail(videoPath, outputPath, timestamp = "00:00:05") {
  return new Promise((resolve, reject) => {
    ffmpeg(videoPath)
      .screenshots({
        timestamps: [timestamp],
        filename: outputPath,
        size: "320x180",
      })
      .on("end", () => resolve())
      .on("error", (err) => reject(err));
  });
}

// Get video metadata
function getMetadata(videoPath) {
  return new Promise((resolve, reject) => {
    ffmpeg.ffprobe(videoPath, (err, metadata) => {
      if (err) reject(err);
      else resolve(metadata);
    });
  });
}

// Usage
async function processVideo() {
  try {
    const metadata = await getMetadata("input.mp4");
    console.log("Duration:", metadata.format.duration);

    await generateThumbnail("input.mp4", "thumb.jpg");
    console.log("Thumbnail created");

    await convertVideo("input.mp4", "output.mp4");
    console.log("Conversion complete");
  } catch (error) {
    console.error("Error:", error);
  }
}
```

## Best Practices

1. **Always specify output format explicitly**
2. **Use -movflags +faststart for web videos** (enables progressive playback)
3. **Test different CRF values** to find quality/size balance
4. **Use hardware acceleration** when available
5. **Monitor progress** for long-running tasks
6. **Set proper error handling** in production
7. **Clean up temp files** after processing
